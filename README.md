Caelestia Shell Setup для Arch Linux
Автоматизированный установщик Hyprland и Caelestia Shell для Arch Linux. Скрипт предназначен для запуска от обычного пользователя с настроенным sudo.

Внимание: скрипт устанавливает системные пакеты, собирает пакеты из AUR и включает системные службы. Перед запуском прочитайте install-caelestia.sh и убедитесь, что понимаете выполняемые действия. Сначала рекомендуется проверить установку на виртуальной машине.

Возможности
Проверяет Arch Linux, права обычного пользователя и доступность сети.
Устанавливает yay, если он ещё не установлен.
Устанавливает Hyprland, порталы Wayland, аудио, шрифты и утилиты.
Устанавливает доступные пакеты Caelestia из AUR, включая Git-версии.
Пытается инициализировать конфигурацию через Caelestia CLI.
Настраивает запуск Caelestia через конфигурацию Hyprland.
Создаёт скрипт перезапуска ~/.local/bin/restart-caelestia.sh.
Настраивает SDDM, если тема Caelestia присутствует в системе.
Создаёт журнал в ~/caelestia-setup.log.
Поддерживает резервное копирование конфигураций и аргумент отката --rollback.
Требования
Чистая или уже работающая установка Arch Linux.
Обычный пользователь с рабочим sudo; запуск от root не поддерживается.
Подключение к интернету.
Достаточно места на диске для пакетов и сборки AUR.
Рабочие репозитории Pacman и доступ к AUR.
Установка одной командой
После публикации файла в публичном репозитории выполните:

bash <(curl -fsSL https://raw.githubusercontent.com/aalex09pas-arch/arch-caelestia-setup/main/install-caelestia.sh)
Команда загружает и сразу запускает текущую версию скрипта. Для более безопасного подхода сначала скачайте файл и прочитайте его:

curl -fL -o install-caelestia.sh https://raw.githubusercontent.com/aalex09pas-arch/arch-caelestia-setup/main/install-caelestia.sh
less install-caelestia.sh
bash -n install-caelestia.sh
bash install-caelestia.sh
При запросе пароля введите пароль своего пользователя для sudo. Не запускайте установщик через sudo или от root.

После установки
Проверьте сообщения установщика и журнал ~/caelestia-setup.log.
Перезагрузите компьютер:
sudo reboot
На экране входа выберите сеанс Hyprland, если он доступен.
Если оболочка не запустилась, войдите в Hyprland и изучите журнал и конфигурацию.
Перезапуск Caelestia:

~/.local/bin/restart-caelestia.sh
Журнал установки:

less ~/caelestia-setup.log
Погода для Черкесска
Установщик предлагает город Черкесск по умолчанию. Автоматическое изменение конфигурации выполняется только если в установленном ~/.config/caelestia/config.json существует поле services.weather.location. Структура конфигурации может различаться между версиями Caelestia; если поле не найдено, настройте город через доступные параметры установленной версии.

Откат конфигураций
Если локальная копия скрипта находится в текущей папке:

bash install-caelestia.sh --rollback
Откат переименовывает пользовательские каталоги конфигурации Caelestia и Hyprland в резервные копии. Он не удаляет установленные пакеты и не отменяет изменения системных служб или SDDM.

Важные замечания
Пакеты AUR могут переименовываться, исчезать или переставать собираться после обновлений.
Скрипт не гарантирует совместимость с каждой конфигурацией оборудования, драйверами NVIDIA или каждым обновлением Arch Linux.
Тема SDDM Caelestia применяется только при наличии каталога /usr/share/sddm/themes/caelestia.
Если уже используется другой дисплейный менеджер, не следует бездумно переключать его на SDDM.
Для NVIDIA, гибридной графики, Secure Boot и нестандартных конфигураций может потребоваться ручная настройка.
Рекомендуется делать резервную копию важных данных и тестировать установку на виртуальной машине.
Устранение неполадок
Скрипт сообщает, что система не Arch Linux

Убедитесь, что установлена именно Arch Linux, а не другой дистрибутив на её основе.

Не удаётся установить пакет из AUR

Проверьте доступность пакета в AUR и повторите попытку позже. Смотрите вывод установщика и ~/caelestia-setup.log.

Caelestia не запускается автоматически

Проверьте, что сеанс Hyprland запускается, команда caelestia доступна, а в ~/.config/hypr/hyprland.conf присутствует строка:

exec-once = caelestia shell -d
Нужна помощь

Создайте Issue в этом репозитории и приложите релевантные сообщения из ~/caelestia-setup.log. Перед публикацией удалите из журнала личные данные.
